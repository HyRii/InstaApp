#CaptureIt

This is a simple social media application developed as a Technical Test Programmer. However, I will continue to develop it. This application is not yet perfect, as the initial design was only a diary, and only a few publicly uploaded posts were included in the feed.

Users can register, log in, create image posts with captions, like, write comments, and access the backend API using Laravel Sanctum.

Backend
- PHP 8.3.11
- Laravel 13

Frontend
- Blade
- Tailwind CSS

Database
- MySQL

Authentication
- Laravel Sanctum

Version Control
- Git
- GitHub
